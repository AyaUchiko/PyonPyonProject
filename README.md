# PyonPyonProject🐇

Developed with Unreal Engine 5

## ■開発ルール

個人開発の進捗を把握し、後から何を、なぜ変更したかが分かるように記録する。

### ■Issue

- 機能追加・不具合修正など、作業単位でIssueを作る。
- やることと完了条件を簡潔に書く。
- 未着手・作業中 のラベルで進捗を管理する。
- 動作確認を行い、main に反映したらIssueを閉じる。

### ■ブランチ

**main では直接作業せず、動作確認済みの変更を毎回マージする。**

基本は機能・役割ごとにブランチを作り、修正・整理用の refactor`ブランチを常設する。

**形式：** `prefix/Issue番号-内容`

| ブランチ名 | 用途 |
| :--- | :--- |
| `feat/1-player-jump` | ジャンプ機能の追加 |
| `asset/2-footstep-sound` | 足音素材の追加 |
| `adjust/3-jump-height` | ジャンプの高さ調整 |
| `refactor` | 修正・整理用として常設 |

### ■コミットメッセージ

**形式：** `prefix: 変更内容`

変更内容は日本語で簡潔に書く。

| Gitmoji | prefix | 用途 | 例 |
| :---: | :--- | :--- | :--- |
| ✨ | `feat` | 機能の追加 | `✨ feat: ジャンプ機能を追加` |
| 🍱 | `asset` | 素材の追加・更新 | `🍱 asset: 足音を追加` |
| 🐛 | `fix` | 不具合の修正 | `🐛 fix: 着地後にジャンプできない問題を修正` |
| 🎨 | `adjust` | 数値・操作感・見た目の調整 | `🎨 adjust: 足場に届くようジャンプ力を上げる` |
| ♻️ | `refactor` | 動作を変えない整理・改善 | `♻️ refactor: 移動処理を関数にまとめる` |
